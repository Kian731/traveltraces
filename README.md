# 旅跡｜個人旅行紀錄

一個不需要安裝或登入的個人旅行紀錄網站。可管理旅程、每日行程、旅行支出、準備清單與目的地筆記；資料會保存在瀏覽器的 `localStorage`。

## 開啟方式

直接開啟 `index.html` 即可使用。若瀏覽器限制本機功能，也可以在此資料夾啟動簡易伺服器：

```powershell
python -m http.server 4173
```

再開啟 `http://localhost:4173`。

## 資料安全

- 「備份」會下載 JSON 檔，建議定期保存。
- 「匯入」會檢查基本格式，並在取代現有資料前再次確認。
- 新版本使用 `travelBookV3` 儲存；若只找到 `travelBookV2` 或舊版 `travelBook`，會嘗試自動遷移。
- 上載的旅程封面會壓縮後一併存在瀏覽器及 JSON 備份中；若空間不足，請改用較小圖片或移除不需要的自訂封面。

## 主要功能

- 依目的地與城市瀏覽旅程
- 首頁可切換「總和／今年」統計，並顯示造訪國家、城市與旅行日
- 新增、編輯與刪除旅行紀錄
- 每趟旅程可直接上載並壓縮獨立封面圖片；未上載時沿用國家圖片
- 可搜尋的國家、出發機場、目的地機場與航空公司欄位
- 依日期建立多個時間點，包含行程、交通、地圖與備註
- 行程日期會依旅行起迄日自動排序並排除已使用日期，時間點可收合
- 回程航班可沿用出國航空公司，也可以獨立設定
- 可選擇國外或國內旅遊；國內旅遊支援航班、客運、火車、高鐵、捷運、開車等主要交通方式
- 城市可在旅程表單輸入後按 Enter 立即加入
- 管理航班、預算、支出平分與個人實付
- 支出使用旅程預算幣別，依旅行日期自動建立可收合區塊，在各日期內新增分類品項，並顯示分類圓形比例圖
- 可搜尋下拉欄位點擊後會顯示完整選項，已有內容也能直接替換
- 旅程內頁以「每日行程／旅行支出／準備清單」頁簽切換內容，減少頁面長度；匯出 PDF 時仍會完整包含三個區塊
- 分類式旅程準備清單與完成度
- 未補齊出發地、目的地或日期時，會標示「待完成記錄」
- 編輯目的地提醒與通用旅行筆記
- 在網站設定管理國家、城市、機場、航空公司與準備清單範本
- JSON 匯入與備份
- Cloudflare Turnstile＋Worker＋D1 同步分享：同一趟旅程可產生固定唯讀連結與協作編輯連結，儲存後其他裝置會在 5 秒內取得最新版
- 協作更新使用獨立編輯權杖與版本衝突保護，避免舊版本直接覆蓋其他裝置的新修改；每組連結可獨立撤銷，預設有效 30 天
- 唯讀旅程可一鍵匯入目前裝置，建立不與原分享者同步的可編輯副本
- 桌面與手機版響應式介面

## 部署同步分享更新

本次協作功能新增了 D1 欄位與 Worker API。第一次上線前，請在 `travel-share-api` 資料夾依序執行：

```powershell
cd "D:\_個人資料\旅遊記錄\travel-share-api"
npx.cmd wrangler d1 migrations apply travel-share-db --remote
npm.cmd run deploy
```

接著將根目錄的前端檔案推送到 GitHub Pages：

```powershell
cd "D:\_個人資料\旅遊記錄"
git add app.js styles.css README.md travel-share-api
git commit -m "Add live trip sharing and collaboration"
git push
```

部署完成後，舊的唯讀連結仍可開啟，但不會自動取得協作權杖；請從旅程內頁重新建立一次分享，才會同時取得「唯讀」與「協作編輯」連結。
