# 旅跡｜個人旅行紀錄

一個不需要安裝或登入的個人旅行紀錄網站。可管理旅程、每日行程、旅行支出、準備清單與目的地筆記；資料會保存在瀏覽器的 `localStorage`。

## 開啟方式

直接開啟 `index.html` 即可使用。若瀏覽器限制本機功能，也可以在此資料夾啟動簡易伺服器：

```powershell
python -m http.server 4173
```

再開啟 `http://localhost:4173`。

## 資料安全

- 「備份」會下載 JSON 檔，建議定期保存。
- 「匯入」會檢查基本格式，並在取代現有資料前再次確認。
- 新版本使用 `travelBookV3` 儲存；若只找到 `travelBookV2` 或舊版 `travelBook`，會嘗試自動遷移。
- 上載的旅程封面會壓縮後一併存在瀏覽器及 JSON 備份中；若空間不足，請改用較小圖片或移除不需要的自訂封面。

## 主要功能

- 依目的地與城市瀏覽旅程
- 首頁可切換「總和／今年」統計，並顯示造訪國家、城市與旅行日
- 新增、編輯與刪除旅行紀錄
- 每趟旅程可直接上載並壓縮獨立封面圖片；未上載時沿用國家圖片
- 可搜尋的國家、出發機場、目的地機場與航空公司欄位
- 依日期建立多個時間點，包含行程、交通、地圖與備註
- 行程日期會依旅行起迄日自動排序並排除已使用日期，時間點可收合
- 回程航班可沿用出國航空公司，也可以獨立設定
- 城市可在旅程表單輸入後按 Enter 立即加入
- 管理航班、預算、支出平分與個人實付
- 分類式旅程準備清單與完成度
- 未補齊出發地、目的地或日期時，會標示「待完成記錄」
- 編輯目的地提醒與通用旅行筆記
- 在網站設定管理國家、城市、機場、航空公司與準備清單範本
- JSON 匯入與備份
- Cloudflare Turnstile＋Worker＋D1 公開唯讀短連結（每條連結可獨立撤銷，預設有效 30 天）
- 唯讀旅程可一鍵匯入目前裝置，建立不與原分享者同步的可編輯副本
- 桌面與手機版響應式介面

## 預設資料說明

- 台灣與馬來西亞出發機場、現有目的地機場以民用客運機場為主。
- 航空公司與航線會持續異動，網站內建的是常用初始名單，請以航空公司及機場公告為準；可在「網站設定」自行維護。
- 機場資料參考 OurAirports 公開資料與馬來西亞民航局（CAAM）機場資料；韓國封面圖片來自 Unsplash。
