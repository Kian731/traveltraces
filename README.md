# 旅跡｜個人旅行記錄

這是一個無需安裝即可開啟的旅行記錄網站原型。直接以瀏覽器開啟 `index.html` 即可使用。

## 資料保存

資料使用瀏覽器的 IndexedDB 儲存在本機，不會因重新整理頁面消失。首頁的「備份資料」會下載 JSON 備份檔。

目前的本機保存適合作為原型；若要在手機、電腦間同步，正式版本應改接 Supabase、Firebase 或自建後端，並加入帳號登入、雲端附件儲存與自動備份。

## 已完成的內容

- 首頁：國家、未來／過去旅程、旅行知識庫
- 國家詳情頁：目的地提醒與該國旅程紀錄
- 新增旅程：航班、日期、機場、旅伴、預算及可自訂欄位
- IndexedDB 本機持久保存與 JSON 備份
